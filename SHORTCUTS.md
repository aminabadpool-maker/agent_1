# Mini-Blender Shortcuts (Blender-Familiar Feel)

## CLI Shorthands (`./mini_blender` / `./mini_blender_pi`)
- `-h` : Show help & shortcuts
- `-i` : Interactive shell mode (desktop build)
- `-p` : Terminal truecolor preview (desktop build)
- `-f <num>` : Start frame
- `-n <num>` : Frame count
- `-c <num>` : Cycle length
- `-o <dir>` : Output directory
- `-s <file.xml>` : Scene XML path
- `-g <x,y,z>` : Grab / move camera offset (Blender `G`)
- `-r <rx,ry,rz>` : Rotate offset in radians (Blender `R`)
- `-z <fov>` : Camera FOV / lens zoom
- `-m <scale>` : Scale multiplier (Blender `S`)
- `-q` : Quiet batch summary mode

## Interactive Shell Commands (`mb>`)
- `g <x,y,z>` : Grab / move
- `r <rx,ry,rz>` : Rotate
- `z <fov>` : Zoom / FOV
- `m <scale>` : Scale
- `reset` (or `alt`) : Reset G, R, Z, M to defaults (Blender Alt+G/R/S feel)
- `1` : Front-ish view preset
- `3` : Side-ish view preset
- `7` : Top-ish view preset
- `0` : Default camera view preset
- `n <count>` : Frame count
- `f <start>` : Start frame
- `s <path.xml>` : Load XML scene
- `p` : Toggle terminal preview
- `render` / `run` : Render batch
- `status` : Print current settings
- `help` : Show commands
- `quit` / `exit` : Exit shell
